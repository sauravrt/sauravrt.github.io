# Technical Catalog - EARS

**Parent LLD**: [Technical Library LLD](./LLD.md)

## Entry Metadata

- [ ] **TECH-CATALOG-001**: Every published Technical entry shall define a title, publication date, description, slug, explicit draft state, format, and artifact URL.
- [ ] **TECH-CATALOG-002**: Every published Technical entry format shall be either `marimo` or `jupyter`.
- [ ] **TECH-CATALOG-003**: Where source code is public, the Technical entry shall provide its source URL.
- [ ] **TECH-CATALOG-004**: Where a related post exists, the Technical entry shall provide a link to that post.
- [ ] **TECH-CATALOG-005**: Before publication, each Technical entry shall undergo a manual required-metadata review.

## Catalog and Entry Pages

- [ ] **TECH-CATALOG-010**: The Technical index shall list every non-draft Technical entry.
- [ ] **TECH-CATALOG-011**: Each Technical-index item shall display only its document title, linked directly to the standalone artifact.
- [ ] **TECH-CATALOG-012**: Each Technical entry shall publish at `/technical/<slug>/`.
- [ ] **TECH-CATALOG-013**: Each Technical entry page shall display a prominent link to its `/labs/<slug>/` artifact.
- [ ] **TECH-CATALOG-014**: The Technical index and entry pages shall not load notebook artifacts in iframes.
- [ ] **TECH-CATALOG-015**: While no Technical entries are published, the Technical index shall display a neutral empty-state message.
