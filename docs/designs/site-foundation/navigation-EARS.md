# Navigation - EARS

**Parent LLD**: [Site Foundation LLD](./LLD.md)

## Global Navigation

- [ ] **SITE-NAV-001**: The site shall display a link from the site title to the home page on every site-rendered page.
- [ ] **SITE-NAV-002**: The site shall display primary navigation links to About, Posts, and Technical on every site-rendered page.
- [ ] **SITE-NAV-003**: While a visitor is viewing a primary section, the site shall identify that section's navigation link with `aria-current="page"`.
- [ ] **SITE-NAV-004**: When the primary navigation is displayed at a viewport width of 320 CSS pixels, the site shall keep every navigation link visible and operable without page-level horizontal scrolling.
- [ ] **SITE-NAV-005**: While JavaScript is unavailable, the site shall keep all primary navigation links visible and operable.

## Contextual Navigation

- [ ] **SITE-NAV-010**: The About page shall provide links to configured external profiles.
- [ ] **SITE-NAV-011**: The site footer shall provide links to configured external profiles.
- [ ] **SITE-NAV-012**: Each post page shall provide a link back to the Posts index.
- [ ] **SITE-NAV-013**: Each Technical entry page shall provide a link back to the Technical index.
- [ ] **SITE-NAV-014**: If a visitor requests an unknown route, then the 404 page shall provide links to Home, Posts, and Technical.
