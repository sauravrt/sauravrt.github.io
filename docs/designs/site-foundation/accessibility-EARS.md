# Accessibility - EARS

**Parent LLD**: [Site Foundation LLD](./LLD.md)

## Keyboard and Structure

- [ ] **SITE-A11Y-001**: Every site-rendered page shall provide a keyboard-focusable skip link whose target is the main content.
- [ ] **SITE-A11Y-002**: When a keyboard user focuses an interactive element, the site shall display a visible focus indicator.
- [ ] **SITE-A11Y-003**: The site shall preserve a logical heading hierarchy beneath each page's primary heading.
- [ ] **SITE-A11Y-004**: The site shall use native links for navigation and shall not require pointer-only interaction.
- [ ] **SITE-A11Y-005**: The site shall declare English as the document language.

## Perception and Reflow

- [ ] **SITE-A11Y-010**: The site's text and interactive controls shall meet WCAG 2.2 AA color-contrast thresholds in both supported color schemes.
- [ ] **SITE-A11Y-011**: The site shall distinguish inline links from surrounding text by more than color alone.
- [ ] **SITE-A11Y-012**: When a site-rendered page is viewed at 320 CSS pixels wide, the page shall not require horizontal scrolling except inside a code, table, equation, or standalone technical-artifact region.
- [ ] **SITE-A11Y-013**: Every informative image stored with a post shall render non-empty alternative text.
- [ ] **SITE-A11Y-014**: Every decorative image shall render an empty alternative-text attribute.

## Manual Review

- [ ] **SITE-A11Y-020**: Before launch, the site shall undergo manual review of page headings, image alternative text, keyboard navigation, visible focus, and contrast.
