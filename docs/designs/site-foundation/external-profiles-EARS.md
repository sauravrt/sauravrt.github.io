# External Profiles - EARS

**Parent LLD**: [Site Foundation LLD](./LLD.md)

## Configuration

- [ ] **SITE-PROFILE-001**: The site shall store each external profile URL in one site-wide configuration location.
- [ ] **SITE-PROFILE-002**: The site configuration shall support a named Flickr profile URL.
- [ ] **SITE-PROFILE-003**: When a configured external profile is rendered, the site shall use a visible text label that identifies the service.
- [ ] **SITE-PROFILE-004**: If an external profile URL is not configured, then the site shall omit that profile link.

## Flickr Scope

- [ ] **SITE-PROFILE-010**: When a visitor activates the Flickr profile link, the site shall navigate to Saurav's configured Flickr profile.
- [ ] **SITE-PROFILE-011**: The site shall not fetch Flickr content through an API during build or page rendering.
- [ ] **SITE-PROFILE-012**: The site shall not embed a Flickr feed or create a local photography-gallery route.
- [ ] **SITE-PROFILE-013**: Before launch, the configured Flickr profile link shall be opened and verified manually.
